# InstantMesh integration

The backend uses the official TencentARC command shape (`python run.py <config> <input> --output_path <dir> --no_rembg`) in a single-threaded worker. Set `INSTANTMESH_REPO` and `INSTANTMESH_PYTHON` to a dedicated official checkout and isolated Python executable; leave both empty to receive a visible failed job rather than a fabricated result. The selected image is resolved internally from the UUID input and an allowlisted artifact name. The optional prompt is stored as metadata and is not passed as geometry conditioning because the official inference CLI is image-driven.

The worker writes run logs and raw OBJ into that job's storage directory, validates finite vertices and face indices, centers and scales a GLB copy, reloads the GLB to verify it contains vertices and faces, and provides both exports. The frontend now polls job status, displays failures, loads completed GLB files in a Three.js viewer, and offers GLB and OBJ downloads. Inference remains unverified until a real InstantMesh environment and GPU sample run are available.
